`sl-logo.svg` is the Storstockholms Lokaltrafik logo as published on
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Storstockholms_Lokaltrafik_logo.svg),
where it is tagged public domain (below the threshold of originality) but
trademarked.

It is kept here for provenance only — nothing loads it at runtime. The widget
draws the mark from `../SlLogo.qml`, whose paths are this file's geometry with
its nested transforms flattened, so the logo can be filled with the active
Omarchy theme colour rather than SL's brand blue.
